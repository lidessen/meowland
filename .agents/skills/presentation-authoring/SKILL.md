# 演示创作与持续改稿

让 agent 和人围绕可运行作品共创。当前交付浏览器演示；PPT 导出是后续能力，不以可导出支持集限制互动，也不承诺已有 PPT/PDF 转换器。

先读作品已有 README、入口与素材说明。新作品参考[可运行样例](../../../examples/presentation/README.md)，以它的实际入口和命令为准；组件能力从 [Meowtail README](../../../packages/meowtail/README.md)与 public exports 核实，不把[设计提案](../../../docs/designs/2026-10-17-presentation-authoring.md)中的草案当作可用 API。复用真实组件和布局，作品只持有内容、实验状态与宿主接线。

## 从内容区域开始选布局

先读[演示内容布局](../../../packages/meowtail/PRESENTATION-LAYOUTS.md)，按观点、依据和操作的关系划分区域，
再放入标题、图片和正文。优先 PresentationLayout 的 header/footer 槽与 single/equal/wide-start/wide-end
命名列比，区域内部继续用 Stack/Grid/AspectRatio；标题、图文、对比、数字、流程、引用与总结是组合配方。
需要第三列时在 single 内使用 Grid，顺序流程保留 ol/li 语义。

占位和真实图使用同一比例容器，替换后检查 contain/cover、裁切和说明。逻辑画布内的列比不随宿主窄屏重排；
Presentation 缩放整张画布。长标题和最终步骤装不下时先精简、拆页或改区域，不靠自动缩字或隐藏溢出交付。
标题确需排印强调时可用 PresentationText editorial/marker，正文保持 plain；它仍是真实可选择文本，
不把原生 contenteditable 接缝描述成编辑器。静态构图与内容清晰度先成立，再选择必要的 transition 入场。
背景先用整场 background 设默认，再逐页完整覆盖；foreground 指文字明暗，搭配底色与遮罩实际检查图片失败后仍可读，关键图片留正文与 alt。

## 尽早运行，再一起改变

短 brief 只需受众、看完改变什么、时长、核心主张、依据/不确定性与硬限制；已有材料一并使用。可推定处写可改假设，只问会改变方向的问题。每个场景用一句话说明目的，互动明确观众改哪个变量、看哪个结果。

粗内容与第一组字体、颜色、排版同时试。已有可运行部分就先看，首轮争取覆盖开场与最难互动，但不等它们同时完成，也不等整稿、大纲批准或素材齐备。图片、视频和音乐可先明确占位；需要比较时做少量真实 A/B，供人看到差异后选择。

每轮依据预览选择最重要的 1–3 个问题，同轮允许改文稿、视觉、素材和互动；再回全场看叙事、密度与节奏，不永久冻结某一层。若人已选 B 排版，只要求改结论和图，就保留该结构，局部 patch 对应文字和资源，不重新生成全场。

只保留必要的 brief、作品源、素材/来源和当前反馈，允许合并文档，不强制四文件、脚手架或台账。普通 Git 检查点与局部 diff 用于比较/回退；实际提交仍按当次授权。

## 课件场景

真实课件入口与教师操作例子见 [Sunshine for all / Welcome](../../../examples/sunshine-welcome/README.md)；其教材版本和课堂活动只属于该作品，不作为所有课件的固定内容或结构。

课件补充目标学生、已有知识与本次学习目标，目标描述学生能解释、应用或判断什么及其依据。记录学科、年级、册次、教材版本和单元；不能仅凭城市与年级猜目录。先核实用户材料或可追溯的教材、课文与参考课件，说明实际读到的是目录、搜索摘要、局部预览还是全文。区分教材原文、他人讲解和自己的改编，不编造缺失正文、页码或标准答案。若用户只要求找参考或课文，先交来源、版本对应关系和待核点，不自行扩成完整单元成品。

沿用共同迭代：把一个已核实的讲解点和关键提问或练习，与字体、颜色、图像和交互一起试成可预览片段；其余材料可以继续核对、明确占位。按预览反馈调整讲解、思考或作答、练习与反馈的节奏，不等全课文案定稿，也不强制每页套固定教案栏目。

每个教学片段先说清“学生做什么、留下什么可观察产出、用什么依据、怎样获得反馈”，再决定页面与呈现顺序；可以只写一句话，不强制教案表格或先定完整大纲。产出可为口头理由、标注或操作，不要求都变成屏幕输入与数据收集。材料多不等于一课时目标多。先试一个关键片段，按真实预览调整任务、用语、密度与支架，保留共同迭代。

教师用现有 step / `Reveal` 控制必要的先后，默认不让媒体结束或计时自动揭晓。问题、提示、参考答案、依据标记分别决定可见时机；原始阅读材料保持可查，标题、图注和句框不要提前泄露学生要推导的结论。需要支架时可从完整表达撤到关键词、句框，再到独立表达，允许再次求助，不把每层都做成必经步骤。Reveal 的 `at` 按步骤累计显现；局部反复显隐由作品普通 signals 接入 `when`，不代表已有逐空练习或支架层级组件。撤架也可只在下一任务不再提供支架。

画布内教学选项直接展开为可点击文字、选项块或卡片，让学生一眼看全，不用下拉 select 藏候选。按钮随本场演示的字体、字号、色彩与形状设计，不把普通应用表单皮肤直接放进 PPT 画布；保留原生语义、键盘、可见焦点和非纯色的选择反馈。提示/参考动作与作答选项在位置和样式上区分。外围播放器目录属于导航，不因课堂选项的原则一并移除。实际例子见[Protecting pandas](../../../examples/protecting-pandas/README.md)，不是新增教学组件 API。

反复显隐的支持区用共享 `Reveal when={shown}`，与 `at` 二选一，保持稳定的阅读区与操作位置；不在作品复制隐藏、焦点与活动许可接线。同时检查默认、各支持单开、全开与收回，不只看全展开。内容样式优先接 `slideClassName`，避免根后代选择器影响外围播放器；容量不够时依共享诊断调整合理构图，不靠透明度、缩字或逐页像素挪动掩盖。参考例注明对应片段，不让固定示例看起来像对当前选择的自动反馈。

翻页/回退、切阶段、重做分别说明保留或重置什么，回退不自动擦除作答。开放题按依据、表达与可讨论的理由反馈，参考例不冒充唯一答案，配对完成也不等于会解释或评价。给独立思考、同伴表达与全班分享留可改的时间预算，并安排每位学生的产出，避免演示内容和少数汇报占满课堂。

制作课件时读[教学片段与改编案例](../../../packages/meowtail/PRESENTATION-LAYOUTS.md#教学片段与可撤回支架)，先借用合适的小组合。贯穿案例按用户指定为“八上 Unit 5 Wild animals — Reading: Protecting pandas”，沿成长信息、问题/后果、保护措施到有依据的个人行动表达组织；活动和句框标明教学改编，未核验的教材原句不补造，不推定版次或页码。它不替换另一作品 Sunshine for all / Welcome。预览重放未提示、提示、参考解释、支架撤回/恢复、前进/回退和明确重做等本片段关键状态，检查键盘、辅助技术隐藏与答案泄露；不以全展开截图代替。需要新增教学能力时再读[研究消化与能力边界](../../../docs/designs/2026-10-18-classroom-authoring.md)，将候选需求与已实现 API 分开，不一次扩建整套教学平台。

引用与素材来源沿用后文的素材约定，教材另记版次、册次与可核页码/课名。参考课件用于比较组织和讲解方法，不把来源标注当作授权整套搬运；文字引用、图片与音视频按实际授权使用，生成素材不冒充课文、教材插图或教学事实依据。

## 让反馈与状态可重看

用稳定 `slideId`、可区分的当轮版本和相关 step/fixture 定位反馈，补一句“哪里不成立、希望改什么”；尺寸仅在相关时记录。人说“第 3 页”时按当轮预览解析到 id。重排不改 id；步骤改义、拆页或删页后重新定位旧反馈，不因旧步号仍合法就宣称复验通过。版本可引用已有截图或工作副本说明，无需版本数据库。

位置、实验输入和运行许可分别处理：所有导航写同一个位置 Signal；每场作品一次创建普通实验 signals，页只引用它们，使选择跨页保留、总结同步，又不让不同作品串值。步骤是可直接呈现的状态，回退不撤销独立实验；实验 reset 由作者明确提供。跳回来源需要恢复原步骤时，作品保存一个普通位置值即可，不扩导航历史系统。

源改动后按现有 Meowbook 工作流重启并 reload，确认是新构建。改前记录与反馈相关的少量输入和位置，改后重放；重复时再形成普通 typed fixture。重载不保证恢复现场，临时参数也不能偷偷成为作品默认值。

## 占位、真实素材与依据

占位写明用途、容器比例、fit/crop 和文字避让；视频另记 poster/讲解点，音乐另记用途，互动另记变量与结果。替换时先保容器和引用关系，再看真实裁切、色彩、文字及行为；语义变了就一起改叙事，不强留旧文案。

轻量来源说明保留原始来源、用途、授权、处理或生成版本及必要 notices，旧引用能回退即可。生成图可帮助表达，不能冒充真实测量、截图或事实证据；数字、画质比较和加载录屏必须对应真实文件与条件，简化公式标明单位和遗漏因素。

图片提供合适 alt，装饰图可空 alt；视频提供字幕或文字替代，音频有可见名称与原生控制。素材生成、上传与持久化由实际工具或宿主承担，不为创作添加资产 registry。按内容需要选媒体，不为覆盖能力强塞音乐。

## 预览、操作与交付

作品整体作为 Meowbook story，关键夹具仍消费同一页源。沿 [Meowbook 合同](../../../packages/meowbook/README.md)和[视觉取证](../ui-development/references/visual-checks.md)发现场景、检查、预览和拍摄，不复制第二套工程命令。审阅/后台实例从首次挂载传 `active=false`；前台实际操作时由宿主开放许可，不能只用文档可见性判断。各预览与正式入口创建独立会话，避免模块级单例。

自定义动画和媒体响应活动许可并登记清理；结构存在不表示可以播放。正常动画、reduced motion、键盘、跨页/回退、暂停、后台与退出按本作品实际能力观察；步骤不重挂整页，互动按键不被翻页抢走。媒体结束不推动叙事，恢复时间不等于恢复声音。`ready`、字体等待、poster 或截图成功不证明所有资源/动画已就绪，等待明确夹具条件，再看实际原图和操作。

正式浏览器入口复用作品 JSX、主题和素材，独立于 Meowbook gallery/开发服务器。交付可运行 Web 产物、可编辑源与资源、依赖/锁文件、来源/notices、剩余占位及准确启动说明；检查 notes 与作者资料是否应进入观众 bundle。显式携带字体、图片、媒体、poster、字幕等，运行时字符串 URL 不代表资源已打包。

关闭开发服务器，从实际交付入口冷启动验证路径、字体、媒体与互动；离线、双击文件或部署子目录按本作品约定分别验收，不默认支持。退出条件是叙事/依据与选定视觉成立、局部修改得到复看、目标尺寸可读、实际使用的控制/清理走通、素材状态和启动方式准确。交付时区分实现、实际观察、未验部分与用户接受；不以截图成功或构建成功代替完成，不自动发布、推送或部署。
