# Meowpress

Meowpress builds a static blog from Markdown and MDX. It ships a theme for posts, short notes and
public skills. This documentation site uses the same generator with its own pages and theme.

## Build and preview

Install Meowpress and its `meowcss` and `meowjsx` peers in a Bun project. Put a Markdown file in
`content/posts/`, then run these commands from the project root.

```sh
bunx --no-install meowpress build
bunx --no-install meowpress preview
```

The build writes `dist/`, which you can deploy to a static host. Set `outputDirectory` in the
config if another tool owns `dist/`. Preview serves the built site at `http://127.0.0.1:4173`.
Put short notes in `content/thoughts/` and public skills in
`skills/<name>/SKILL.md`. Publishing `.agents/skills/` requires `includeProjectSkills: true` in
the config.

## Use existing content folders

Create `meowpress.config.ts` in the project root if your posts or notes live elsewhere.

```ts
import { meowSite } from "meowpress/build";

export default meowSite({
  content: {
    directory: ".",
    postsDirectory: "blog",
    thoughtsDirectory: "notes",
    assetsDirectory: "blog/assets",
  },
});
```

Posts still appear under `/posts/` and notes under `/thoughts/`. The build also writes `llms.txt`
and `agents.md` alongside the site. Call `buildSite()` from `meowpress/build` when you need to run
the build from your own script.

## Content

A post is a Markdown or MDX file with optional frontmatter. The first heading becomes its title
when there is no frontmatter title.

```md
---
title: A note about the runtime
---

The body of the note.
```

MDX executes code at build time, so use trusted files. MDX pages may use components supplied by the
site, which is how this site embeds a live story in a package page.

## Pages a consumer owns

A consumer that supplies its own pages owns the whole site map. The provider receives the content
that was already loaded and returns complete documents; the package writes them at their paths and
adds them to the agent-facing indexes.

```ts
meowSite({
  // ...
  pages: ({ posts }) =>
    posts.map((post) => ({
      path: post.slug,
      title: post.title,
      html: renderDocument(post),
    })),
});
```

<Callout tone="note">
  The package's own blog routes are not published alongside a consumer's pages. One site map, one
  owner.
</Callout>
