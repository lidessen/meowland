# MeowSlides

MeowSlides is the presentation package. It owns the player, pages and steps, the reveal mechanism,
the media lifecycle, the presentation layouts and themes, and the trusted local MDX authoring entry
point. It depends on Meowtail, MeowJSX and MeowCSS in one direction only; Meowtail does not depend
on it.

## What a slide is

A slide has an id, a title and a render function. Set `steps` to the number of advances after the
initial view, then use `Reveal` at the matching step.

```tsx
import { h } from "meowjsx";
import { Presentation, Reveal, type SlideDefinition } from "meowslides";

const deck = [
  {
    id: "opening",
    title: "One render graph",
    render: () => <h1>One render graph</h1>,
  },
  {
    id: "detail",
    title: "The next point",
    steps: 1,
    render: () => (
      <section>
        <h2>The next point</h2>
        <Reveal at={1}>It arrives on a step.</Reveal>
      </section>
    ),
  },
] satisfies readonly SlideDefinition[];

export const example = <Presentation title="One render graph" slides={deck} />;
```

## Trust boundary

MDX slides are trusted local code: the authoring entry point compiles a file the author already
owns. Arbitrary uploaded or generated text is not executed; it is rendered as data.

<Callout tone="note">
  The presentation player, the reveal mechanism and the presentation themes used to live in
  Meowtail. They moved here, and the old `meowtail/presentation` exports are gone.
</Callout>
