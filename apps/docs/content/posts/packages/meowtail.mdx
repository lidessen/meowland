# Meowtail

Meowtail is the component library the rest of Meowland is built from. It owns the cross-application
components, the semantic layout, the standard theme and the complete Assistant composition.
Networking, execution, permissions and persistence stay with the host.

## A component declares, the theme paints

The component is an ordinary function with typed `.meta`; style declarations stay on the metadata object while selectors use the CSS part descriptors.

```tsx
import { type Context, type Props, createRuntime, h } from "meowjsx";
import "meowjsx/web";
import { createWebRenderer } from "meowjsx/web";
import { cx, defineOptions } from "meowcss";
import { applyTheme, mountStyles } from "meowcss/web";
import { css, defineStyleProps, parts, type ThemedProps } from "meowcss/meowjsx";
import { createMeowUI } from "meowtail";
import { extendStandardTheme, ui, uiTokens } from "meowtail/theme";

export const calloutOptions = defineOptions("callout", {
  tone: ["neutral", "accent"],
});

export interface CalloutProps extends Props, ThemedProps<typeof calloutOptions> {
  title: string;
}

export function Callout(
  { title, children, ref, className, ...props }: CalloutProps,
  context: Context<typeof Callout>,
) {
  return (
    <aside
      {...props}
      className={cx(className, ui.bg.fill, ui.text.secondary)}
      ref={[context.parts.root, ref]}
    >
      <strong ref={context.parts.title}>{title}</strong>
      {children}
    </aside>
  );
}
Callout.meta = {
  name: "callout",
  parts: ["root", "title"],
  style: defineStyleProps(calloutOptions, { defaults: { tone: "neutral" } }),
} as const;

const callout = parts<typeof Callout>("callout");
export const calloutTheme = extendStandardTheme({
  styles: [
    css`
      ${callout.root} {
        border-radius: ${uiTokens.radius.lg};
        padding: ${uiTokens.space.group};
        border: ${uiTokens.line.width} solid ${uiTokens.line.edge};
      }
      ${callout.root}[${calloutOptions.attribute("tone")}="accent"] {
        ${uiTokens.accent.line};
      }
      ${callout.title} {
        font-weight: ${uiTokens.type.weight.semibold};
      }
    `,
  ],
});

const calloutRuntime = createRuntime({ plugins: [createMeowUI({ components: [Callout] })] });
const calloutRenderer = createWebRenderer(calloutRuntime);
const document = globalThis.document;
mountStyles(document, calloutTheme.cssText);
applyTheme(document.documentElement, calloutTheme);
calloutRenderer.render(
  h(Callout, { title: "Saved", tone: "accent" }, "Your changes are ready."),
  document.querySelector("#callout"),
);
```

The component binds its finite parts with `context.parts`, and the theme selects them with typed CSS descriptors. `cx` composes class values from `ui`; the standard theme includes those utility declarations. The style plugin writes the part and option attributes during rendering, so components never set those attributes by hand.

## Three steps to a working page

Importing components is not enough. A page needs the component registry installed on its runtime,
the theme stylesheet mounted, and the theme root bound to the document.

```tsx
import { createRuntime, h } from "meowjsx";
import { createWebRenderer } from "meowjsx/web";
import { Button, createMeowUI, meowUIComponents } from "meowtail";
import { standardTheme } from "meowtail/theme";
import { applyTheme, mountStyles } from "meowcss/web";

const runtime = createRuntime({
  plugins: [createMeowUI({ components: meowUIComponents })],
});
const renderer = createWebRenderer(runtime);
const document = globalThis.document;

mountStyles(document, standardTheme.cssText);
applyTheme(document.documentElement, standardTheme);
renderer.render(h(Button, null, "Save"), document.querySelector("#app"));
```

## This site is made of it

Every frame, table, badge and link on this site is a Meowtail component, painted by a theme that
extends the standard theme. The site does not carry a second palette or a second radius scale.
