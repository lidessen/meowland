# 演示入场过渡

本轮为现有 Presentation / Reveal 补浏览器入场装饰，沿用同一位置来源、单当前页挂载及活动许可；不引入时间轴、动画框架或 PPT 导出。独立质疑者核查了快速导航、初次挂载、嵌套 Reveal、动画取消及媒体清理反例后同意此有界方案。

`transition` 在两组件使用同一合同：`none | fade | slide | zoom`，或 `{ effect, direction?, speed? }`。默认 none 保持旧作品。speed 为 fast / normal / slow（160 / 280 / 420ms）；方向为物理移动方向，left 从右向左进入，up 从下向上进入。未指定时切页按数组顺序前进 left、后退 right；Reveal 默认 up。fade / zoom 不使用方向。

切页只给新页入场，旧页立即停止并卸载；不提供需要旧页推出或保留快照的 push。页序与 step 是叙事状态，动画不延迟导航，不保留旧交互或媒体。页内容仍可在入场时正常交互。Reveal 的阈值决定可见、inert 与活动；动画只装饰已经挂载的隐藏到显现，不改变几何或延迟隐藏。初始直达、祖先许可恢复或父 Reveal 显现不会补播内层动画。

使用原生 Web Animations，仅装饰 opacity / translate / scale，保留画布已有 fit transform。切页期间在既有 stage 暂时裁切入场画面，结束或取消统一恢复；viewport 的 actual-size 滚动合同不变。快速导航先取消旧装饰，只在最新导航对应的下一帧开始；减少动态、活动撤销、卸载和后续导航都终止装饰并呈终态，恢复许可不重播。SSR、缺少动画能力或浏览器拒绝动画时呈终态。

独立审查要求的回归包括快速前后/跨目录导航、旧媒体停播与 DOM 移除、同页步骤不重挂、嵌套阈值、焦点回退、活动/文档隐藏/减少动态撤销，以及缩放与 actual-size 下临时裁切恢复。最终证据由本轮回执记录，不从静态图推定动画正确。
