# Signal-entry alpha publication

The release source is [`622af70`](https://github.com/lidessen/meowland/commit/622af70194d2a09fcdab6446008f946794a38059). It adds the DOM-free `meowjsx/signal` entry and removes the lifecycle signal, shadow, and renderer mount aliases. The published older Tail and Slides call `context.signal`; their previous JSX peer range would accept another `0.2.0-alpha.N` and permit a broken combination. The new prerelease minor cohort has disjoint peer ranges, so an installation of the old Slides alpha still selects the older JSX/CSS/Tail cohort. Book and Press implementation did not change; their new versions update peers to join the new cohort.

## Slides remains unpublished on the new cohort

Its frozen SHA256 is `35961cd8cafdbf88839781f5b6a8e8e5d863820af534bf45aa93b6566d1ab3bb`. The [Slides-only Actions run](https://github.com/lidessen/meowland/actions/runs/40160387998) at `4040d65` passed its prepare job, then its OIDC `npm publish` exited with `ENEEDAUTH` and no publish response. A subsequent public registry read found no `0.2.0-alpha.0`; Slides `alpha`, `dev`, and `latest` still point to `0.1.0-alpha.1`. No second publish, token, direct CLI fallback, or Trusted Publisher change was made.

The first Slides publication did not configure its persistent Trusted Publisher. The owner must separately authorize and configure the `meowslides` npm package for GitHub Actions repository `lidessen/meowland`, workflow filename `npm-release.yml`, no environment, and direct `npm publish` permission. `npm dist-tag` permission is also needed to move Slides `dev` after a successful alpha publication. Then inspect the unchanged registry and the failed run's retained tarball artifact before resuming the same bytes. The old Slides alpha remains independently installable: a clean public npm install resolved Slides `0.1.0-alpha.1`, JSX/CSS `0.2.0-alpha.0`, and Tail `0.3.0-alpha.0` and imported their runtime entries. It cannot be mixed with the new JSX/Tail cohort in one runtime.
