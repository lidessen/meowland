# 图片与录屏来源

本作品素材均为 Meowland 原创，适用仓库 MIT 许可证；无图库、外部生成服务、第三方字体或音乐。

- `coast-original.png`：`../scripts/generate-images.ts` 生成的确定性海岸插画，2200×1400，3,634,345 bytes。不是摄影或网络事实证据。
- `coast-delivery.jpg`：该 PNG 的 FFmpeg `-q:v 14` JPEG 编码，同尺寸，68,426 bytes；细纹和边缘有所损失，不声称画质相同或比例普适。
- `local-transfer.webm`：`../scripts/record-transfer.ts` 录下真实本地 HTTP 请求与解码，静音 VP8，约 12 秒；受控分块发送只作说明，非公网基准。实际条件和结果见 [recording.json](recording.json)。
- `local-transfer.vtt`：原创英文字幕；证据页另有常显文字替代。

估算与显示使用十进制 bytes/kB/MB/Mbit/s，忽略延迟、服务端、解码、缓存和变化；热缓存可能免去传输。系统本地 sans-serif 字体不随产物分发。

原独立测试纯音已迁往 Meowslides 的 PresentationAudio story，不再是本作品素材；其合成方法与许可在组件故事 assets/NOTICES.md 中保留。
