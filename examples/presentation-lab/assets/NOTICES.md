# Asset provenance

All image and audio source material in this example is original Meowland material, licensed under the repository MIT license. No stock images, external generation services, third-party fonts or music are used.

- `coast-original.png`: original deterministic raster illustration, generated by `../scripts/generate-images.ts`, 2200 × 1400 pixels, 3,634,345 bytes. It is an illustration, not a photograph.
- `coast-delivery.jpg`: JPEG encoding of that PNG at the same dimensions, produced by FFmpeg `-q:v 14`, 68,426 bytes. Fine texture and edges change; quality is not identical. The size ratio is specific to these files.
- `quiet-tone.wav`: original six-second 220 Hz sine tone with fade-in/out, FFmpeg lavfi sine generator at 44.1 kHz. Separate optional media check, never autoplayed.
- `local-transfer.webm`: local browser recording generated by `../scripts/record-transfer.ts`. Real HTTP image fetches from a loopback server with deliberately paced chunks. The imposed schedule is illustrative, not an uncontrolled network benchmark. Silent VP8 WebM, approximately 12 seconds.
- `local-transfer.vtt`: original English captions. The evidence page also provides an always-visible text alternative.

Byte and transfer units are decimal: kB = 1,000 bytes, MB = 1,000,000 bytes, Mbit/s = 1,000,000 bits per second. The estimate excludes latency, server work, decode, cache and variable throughput. Generated illustrations are not presented as factual evidence of network performance.

Typography uses the operating system's local sans-serif stack intentionally. No font is downloaded or redistributed. Different systems can choose a different local font; the delivered layout must still fit.
