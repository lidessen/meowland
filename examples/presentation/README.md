# Minimal browser presentation: Read a landscape

Authors mainly edit [slides.mdx](slides.mdx): plain Markdown, two columns, images, progressive reveal and a classroom question.
For a complete custom interactive explainer see the [image-loading work](../image-loading/README.md); generic media scenarios and stress verification belong to Meowslides stories/tests and are not the starting point of every script.

To begin you only need a `slides.mdx` like the one below, with no imports, page arrays or `Slide` declarations:

```mdx
# Observe first

Describe what you can see.

---

# Explain with evidence

Use one visible detail to support your claim.
```

Outline titles, default layout and typography are generated by the tooling. This directory's seven-page script continues to show optional two columns, images, reveals, interaction and audio;
when those capabilities are unnecessary, the corresponding pages or TSX files need not be kept. When a page needs a long-lived reference, fill in a stable id explicitly.

The complete Panda courseware lives separately in [examples/protecting-pandas](../protecting-pandas/README.md) and is not part of this minimal example. Once same-version packages are ready, run from the repository root:

```sh
bun examples/protecting-pandas/build.ts
bun examples/protecting-pandas/serve.ts
```

Open `http://127.0.0.1:13014/`. The courseware is kept independently, and its teaching content is not copied into this example.

## Preview and build

First install dependencies and build packages in a same-version Meowland checkout according to the root README, then run from the repository root:

```sh
bun run --cwd examples/presentation dev
bun run --cwd examples/presentation build
```

`dev` rebuilds and refreshes the browser automatically; this is a full page reload that starts a new session, not state-preserving HMR.
It opens `http://127.0.0.1:3030/` by default; use `bun run --cwd examples/presentation dev -- --port 13029` to choose a port.
`build` outputs `dist/`, which you open with an ordinary static HTTP server; double-clicking `file://` is not supported by default.
The current package split and MDX tooling are not yet published; do not use an old npm package to stand in for the same-version environment.

## What authors write

- Plain text, lists and images use Markdown directly; the default theme handles typography.
- A top-level `---` surrounded by blank lines breaks pages; horizontal rules inside code fences and nested content do not break pages.
- The first `#` heading on each page is used for both the screen and the outline and is shown only once. `Slide id` provides stable anchoring; keep the id when changing the title.
- Two columns are written explicitly with `<Slide columns={2} />` and two groups of `<div>` content; do not guess left/right from paragraph counts.
- `Reveal at` together with the page's `steps` controls presentation order; interactive choices do not automatically change pages or reveal answers.
- Custom classroom logic is in [QuickCheck.tsx](components/QuickCheck.tsx), continuing to use ordinary MeowJSX signals and generic components.

The question's `createSession` is created once per presentation, and choices plus feedback persist across pages; only `Reset check` clears this question, and refreshing creates a new session.
In MDX, import only factories and components, and do not put mutable signals at module top level so different presentations leak values.
Authors do not copy main, server, build scripts, theme assembly, component registration or media declaration files.
`tsconfig.json` is only for repository maintainers to check custom TSX components; it is not required for the MDX tooling to start or for regular authors.
MDX is trusted local code, reviewed like normal source; it is not a runtime entry that accepts untrusted uploaded content.

The assets are original repository illustrations and a six-second pure tone; see [NOTICES](assets/NOTICES.md) for sources.
This example does not depend on Meowbook; meowbook component scenes and complex work fixtures can still be used independently.
