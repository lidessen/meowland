# Asset sources

This example reuses original Meowland assets under the repository's MIT license; there are no third-party images, fonts or music.

- `coast-delivery.jpg`: a JPEG encoding of the original procedural coast illustration, 2200 × 1400, 68,426 bytes. The original artwork and generation script are kept in [image-loading](../../image-loading/assets/NOTICES.md). This is an illustration, not photography or scientific evidence.
- `quiet-tone.wav`: an original six-second 220 Hz sine tone at 44.1 kHz with fade in and out. It is used for an optional manual media demonstration, not as an ambient recording.

This example does not modify the assets. The image keeps its description; the audio does not play by default, and the shared presentation media components respond to page activity permission and release resources.
