# Sample asset sources and licenses

`quiet-tone.wav` is an original six-second 220 Hz sine test tone generated by Meowland with FFmpeg
lavfi sine, 44.1 kHz, mono, with fade in and fade out. It is not a musical work, a field recording or
a third-party asset, and it follows the repository's MIT license.

This file moved from the original image-loading example to the component stories; it keeps the
original audio bytes and is not re-encoded. It demonstrates the media behavior of a standalone
soundtrack across pages and controlled visibility; it does not autoplay: the preview host grants
permission first, and then the user explicitly starts it.
